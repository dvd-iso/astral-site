# Escopo do astral-site

- Este repositório contém o site público do Astral, seus arquivos visuais, a configuração do site e as instruções de acesso.
- Construções, schematics, datapacks, itens, modelos, texturas do jogo, configurações do mundo e MOTDs pertencem ao repositório `dvd-iso/astral-plugin`, disponível localmente em `../astral-plugin/`.
- Pedidos relacionados ao jogo devem ser implementados e commitados no `astral-plugin`. Pedidos de HTML, CSS, JavaScript, páginas e instruções de acesso do site pertencem a este repositório.
- `marca/fluxer-icon.png` é uma imagem usada pelo README do site. Os geradores da marca e os materiais do servidor estão em `astral-plugin/marca/`.
