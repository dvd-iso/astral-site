# Escopo do astral-site

- Este repositório contém o site público do Astral, seus arquivos visuais, a configuração do site e o Worker de whitelist.
- Construções, schematics, datapacks, itens, modelos, texturas do jogo, configurações do mundo e MOTDs pertencem ao repositório `dvd-iso/AtlasHistoria`, disponível localmente em `../AtlasHistoria/`.
- Pedidos relacionados ao jogo devem ser implementados e commitados no `AtlasHistoria`. Pedidos de HTML, CSS, JavaScript, páginas e whitelist do site pertencem a este repositório.
- `marca/fluxer-icon.png` é uma imagem usada pelo README do site. Os geradores da marca e os materiais do servidor estão em `AtlasHistoria/marca/`.
