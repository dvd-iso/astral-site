# Logotipos dos launchers

Imagens oficiais usadas para identificar os launchers na escolha de instalação.
As marcas pertencem aos respectivos titulares.

- **Prism Launcher** — [arquivo oficial](https://prismlauncher.org/img/logo.svg).
  Autoria: Prism Launcher e os colaboradores listados nos metadados do SVG.
  Licença: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
  Desenho e cores preservados.
- **SKlauncher** — [arquivo oficial](https://next.skmedix.pl/images/logo.svg).
  Desenho branco preservado, como no site oficial para fundo escuro.
- **Modrinth** — [arquivo oficial](https://github.com/modrinth/code/blob/main/packages/assets/branding/logo.svg).
  Desenho preservado; a cor verde foi definida na raiz para exibição como imagem.

Os SVGs são servidos pelo próprio site. Use `object-fit: contain` e renderização
normal para preservar proporções e curvas, inclusive nas versões menores.
